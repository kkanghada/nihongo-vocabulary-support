개인정보 처리방침

멍이냥이 수첩 · 시행일: 2026년 10월 8일

1. 기기에 저장하는 정보

앱은 회원가입과 로그인을 요구하지 않습니다. 프로필, 생일, 처음 함께한 날, 일정, 건강·생활 기록, 병원 정보, 선택한 사진과 설정을 사용자 기기에 저장합니다. 개발자는 이러한 앱 기록을 서버로 수집하거나 보관하지 않습니다.

2. 사진과 알림

사용자가 선택한 사진은 프로필 및 기록에 사용하며 기기에 저장합니다. 사진을 선택하는 행위만으로 개발자에게 사진이 전송되지는 않습니다. 알림 권한을 허용하면 일정 제목 등을 포함하는 기기 내 알림을 예약합니다. 권한은 iPhone 설정에서 변경할 수 있습니다.

3. 백업과 공유

사용자가 백업하거나 공유하면 기록과 사진이 포함된 파일 또는 추억 이미지가 생성됩니다. 백업 파일은 암호화되지 않았습니다. iOS 공유 시트에서 선택한 앱이나 저장 위치로 파일을 전달하는 경우 해당 서비스의 개인정보 처리방침이 적용됩니다. 기기에 있는 파일과 공유한 사본은 사용자가 직접 관리하고 삭제해야 합니다.

4. 광고 서비스

앱에는 Google AdMob 광고 연동 기능이 포함되어 있습니다. 광고 단위 ID가 설정되지 않으면 광고 SDK를 초기화하거나 광고를 요청하지 않습니다. 광고를 활성화한 빌드에서는 Google Mobile Ads SDK 및 동의 관리 기능이 사용되며, Google이 광고 제공과 부정 사용 방지 등을 위해 IP 주소, 기기 식별자, 광고 상호작용 정보와 진단 정보를 처리할 수 있습니다.

실제 처리 항목은 SDK 버전, 광고 설정, 지역 및 사용자 동의에 따라 달라집니다. 관련 지역에서는 광고 동의 화면이 표시될 수 있습니다. 반려동물 기록과 사진을 광고 요청에 직접 첨부하지 않습니다. 자세한 내용은 Google 개인정보처리방침과 Google Mobile Ads SDK 데이터 안내에서 확인할 수 있습니다.

5. 보유와 삭제

기록은 앱에서 수정하거나 삭제할 수 있습니다. 삭제한 기록은 휴지통에 보관되며 복구할 수 있습니다. 앱을 기기에서 삭제하면 앱 내부 데이터도 삭제될 수 있습니다. 별도로 저장하거나 공유한 백업·이미지 파일은 앱 삭제로 없어지지 않습니다. 개발자가 사용자 기록을 서버에 보유하지 않으므로 서버 계정 삭제 절차는 없습니다.

6. 문의 시 제공하는 정보

이메일 문의 시 사용자가 제공한 이메일 주소와 문의 내용은 문의 응답과 문제 해결을 위해 사용합니다. 민감한 기록, 사진이나 전체 백업 파일은 첨부하지 마세요. 이메일 서비스에는 해당 제공자의 정책이 적용됩니다.

기능과 정보 처리 방식이 변경되면 이 페이지를 수정하고 시행일을 갱신합니다. 개인정보 관련 문의는 dadogeeann@gmail.com으로 보내주세요.
